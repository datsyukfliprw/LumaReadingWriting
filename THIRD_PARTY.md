# Third-party and reference notes

## Koggle

Koggle by Kyle Clapper was reviewed as an architectural reference. Its public repository is MIT licensed. This Luma implementation is newly written rather than a source-level merge, but the project intentionally follows the useful idea of separating UI, game control/domain logic, and solving logic.

## Babbling Bubbles

Babbling Bubbles by dtressel was reviewed as a behavioral reference for interactive word-grid concepts such as path selection, live word construction, scoring feedback, and changing game state. GitHub currently exposes no repository license for that project, so its source was **not copied into Luma**. Those interaction concepts were independently implemented here.

## Runtime packages

See `package.json` and the installed package metadata for the licenses of npm dependencies used by this project.
